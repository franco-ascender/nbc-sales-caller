## Cómo revisar

1. Entrar en la URL normal con la cuenta NBC. Refrescar y abrir otra pestaña: se restaura la sesión dentro de la ventana12h.
2. Overview → Edit. Arrastrar tarjetas, usar esquina inferior para ancho/alto, X para quitar. Add widget → elegir tamaño, agregar, Done. Recargar conserva layout. Cancel revierte una edición; Restore vuelve a la distribución inicial.
3. Sol/luna arriba: cambiar apariencia y recorrer Calendar, Caller, Academy, Lead Engine y Members; mantiene el tema. Sidebar se puede ocultar.
4. Calendar muestra agenda nativa. Hasta confirmar el calendario de mentoría y autorizar lectura externa, se indica que falta conectarlo. No se deben esperar llamadas ficticias.
