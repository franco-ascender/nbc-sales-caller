## Datos, APIs y configuración

Migración `040`: tres tablas propias, sin modificar Members o call_sessions. Estado **APLICADA Y VERIFICADA** en Supabase real (HTTP 201, 2026-09-14T21:21:55Z), SHA256 `ff38858e0fd900a44a8926e1b60e9e859a245f8c6735c1c50f6f59c9ddb2097f`. Evidencia `migration-live.json` y `live-verification.json`: import simultáneo/reintento, versiones, aislamiento y permisos/RLS reales. `caller_leads`: UUID, operator_id FK auth.users, nombre/teléfono normalizado/email/empresa/source, etapa/notas y timestamps; UNIQUE(owner,phone), índice owner/fecha/ID. `caller_imports`: owner/request PK, fingerprint y conteos. `caller_voice_jobs`: ID único global, owner, descripción/nombre, preparando/completado/incierto, voice_id. RLS habilitado sin políticas cliente; revocados todos los privilegios public/anon/authenticated; service_role select/insert/update. RPC `caller_import_leads(uuid,uuid,jsonb)` security invoker, búsqueda fija public, lock transaccional por owner, execute solo service_role. No rollback destructivo automático.

- GET `/api/workspace/session`: contrato I02 heredado, Bearer Auth + membresía activa → `{user:{id,name,role}}`; 401/403/503.
- Sessions GET/POST/sync/reconcile: payloads C01 iguales, ahora cualquier miembro activo; consultas siempre por UUID propio. Sin token/token inválido 401; inactivo 403; sesión ajena 404. Cursor fecha+UUID/límites conservados.
- GET `/api/caller/leads`: miembro → `{leads,configured,hasMore}`, últimos 1.000 de su UUID. Esquema ausente devuelve configured:false.
- POST leads: `{requestId,leads:[{name,phone,email?,company?,source?}]}`, 1–500, JSON≤512 KiB; → `{imported,duplicates,replayed}`. 400 inválido, 409 referencia usada con otro payload, 413 cuerpo grande, 415 media type, 503 almacenamiento.
- PATCH leads: `{id,stage,notes,updatedAt}`, JSON≤8 KiB → `{lead}`. 404 ajeno/ausente, 409 versión obsoleta, 400 inválido, 503 DB. IDs propietarios del cliente no participan en autorización.
- GET voices: admin, `?cursor` opaco acotado → `{voices:[{id,name,description,previewUrl}],nextCursor,currentVoiceId}`. Proyecta campos seguros y URL de preview HTTPS permitida.
- PATCH voices: admin, `{voiceId}` → `{voiceId}`, verifica disponibilidad y PATCH mínimo de TTS. 400/404/409/502/503.
- POST voices: admin, `{requestId,name,description,acceptServiceUsage:true}` → `{voiceId,replayed}`. Nombre≤80, descripción20–1.000, cuerpo≤8 KiB. 409 para intento previo incierto/diferente; 502 no confirmado; 503 DB/config. Nunca retry automático de generación.
- Todo no-store. Errores no devuelven payload privado de proveedor.

Variables sin valores: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY, SUPABASE_SECRET_KEY, NBC_OPERATOR_EMAIL, ELEVENLABS_API_KEY, ELEVENLABS_AGENT_ID. Operación local autorizada: SUPABASE_PROJECT_REF, SUPABASE_ACCESS_TOKEN, VERCEL_TOKEN, VERCEL_TEAM_ID, VERCEL_PROJECT_ID. No .env en snapshot.
